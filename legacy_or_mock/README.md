# Thư mục lưu trữ mã nguồn Mock / Tham khảo (Legacy & Mock)

Thư mục này dùng để lưu trữ các thành phần prototype / mock server phục vụ việc tham khảo hoặc thử nghiệm độc lập:

- `mock-node-api/`: Mock API viết bằng Node.js & Express (hỗ trợ JWT và bộ lọc ủy quyền vai trò để kiểm thử nhanh logic IDTTX-20 trước khi hoàn thiện trên Java Servlet).

> **Lưu ý:** Mã nguồn chính thức của Backend hệ thống được triển khai trên **Java Servlet / JSP** đặt tại thư mục chuẩn `src/` và quản lý bằng Maven qua `pom.xml`.
